# Ajie C. Javier Portfolio

A secure dynamic portfolio website built with PHP and MySQL for AJie C. Javier. The project includes a public portfolio, admin dashboard, and editable content management for profile, skills, projects, education, experience, and settings.

## Features

- Dynamic public portfolio home page
- Skills management with proficiency and categories
- Project CRUD with publishing rules and project links
- Education and experience management
- Profile editor for personal details and social links
- Site settings editor for title and theme configuration
- Admin login with session protection and CSRF checks
- Contact message tracking for portfolio inquiries
- Database-backed data instead of static-only content

## Requirements

- PHP 8.1+
- MySQL 8.0+
- Apache or Nginx web server
- Composer is optional unless additional PHP libraries are added later

## Quick start

1. Clone the repository.
2. Create a MySQL database named `portfolio`.
3. Import `database/schema.sql` into the database.
4. Copy `.env.example` to `.env` and adjust the database credentials.
5. Make sure the project is served from the repository root.
6. Open the site in a browser and log in to the admin panel.

## Environment setup

Create a local `.env` file based on `.env.example`:

```env
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=portfolio
DB_USER=root
DB_PASS=
```

The app loads environment variables from `.env` automatically through `includes/db.php`.

## Admin setup

The schema creates the `admins` table, but no default admin account is seeded for security reasons.

Create the first admin account manually in MySQL using a password hash generated by PHP:

```php
<?php
$passwordHash = password_hash('your_secure_password', PASSWORD_DEFAULT);
echo $passwordHash;
```

Then insert a row into the `admins` table with a valid email and display name.

Example:

```sql
INSERT INTO admins (email, password_hash, display_name)
VALUES ('admin@example.com', '$2y$10$yourHashedPasswordHere', 'Admin');
```

Then log in through the admin login page:

```text
http://localhost/admin/login.php
```

The schema and starter records live in:

- `database/schema.sql`
- `database/README.md`

Keep database credentials and administrator passwords out of public repositories. Do not commit real secrets.

## Security

- Admin pages require login.
- CSRF tokens are enforced on admin POST requests.
- Passwords are stored as password hashes.
- `.env` is not committed.

## Deployment

For deployment, use HTTPS, store secrets in the hosting environment, and keep PHP and MySQL updated. Restrict admin access to trusted users only.
